# UrDU Yoshlar Ittifoqi BT — Rasmiy Portal

Urganch davlat universiteti Yoshlar ittifoqi boshlang‘ich tashkiloti va Yetakchilar Kengashi rasmiy portali.

## Texnologiyalar

- React 19
- Vite 7
- React Router 7
- Tailwind CSS 4
- Motion (Framer Motion) + GSAP + Lenis
- Lucide Icons
- COBE globe

## Asosiy Bo'limlar

- **Hero** — Universitet shiori, chaqiriq va asosiy navigatsiya
- **Statistika & Identitet** — UrDU ramzi, muddat, xalqaro hamkorlik globusi va axborot
- **Yetakchilar Kengashi** — Bosh yetakchi va 6 ta asosiy yo'nalish koordinatorlari
- **Yo‘nalishlar & Klublar** — Intellektual, harbiy-vatanparvarlik, innovatsiya, ijtimoiy yo'nalishlar
- **Yangiliklar** — Universitet hayoti, xakatonlar va yutuqlar
- **Imkoniyatlar (Behind Curtains)** — Davlat stipendiyalari, Startaplar va Xalqaro almashinuv
- **Aloqa & Manzil** — Takliflar shakli, telefon, email va ijtimoiy tarmoqlar

## Loyihani Ishga Tushirish

1. Qaramliklarni o'rnatish:
```bash
npm install
```

2. Ishlab chiqish serverini ishga tushirish:
```bash
npm run dev
```

3. Ishlab chiqarish (production) uchun yig'ish:
```bash
npm run build
```

4. Preview qilish:
```bash
npm run preview
```
